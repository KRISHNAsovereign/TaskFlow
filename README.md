# TaskFlow AI - Intelligent Task Management

TaskFlow AI is a professional MERN stack productivity platform featuring task tracking, progress analytics, and an AI-powered goal decomposition tool.

## Tech Stack
- **Frontend:** React (Vite), Axios, React Router
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **Security:** JWT, Bcrypt, Helmet, CORS, Rate Limiting

## Setup Instructions

### Backend
1. `cd backend`
2. `npm install`
3. Create `.env` from `.env.example`
4. `npm start`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
